\section{Implementation and Benchmark Details}
\label{app:details}

\subsection{Hardware and software environment}

All release measurements were taken on a single machine: AMD Ryzen 7 5800H
(16 logical CPUs), Ubuntu WSL2 (kernel 6.6.87.2-microsoft-standard-WSL2),
Python 3.14.4 built with GCC 15.2.0. Processes were pinned with
\texttt{taskset} to CPUs $\{0, 2, 4, 6\}$ (one hardware thread per physical
core) with \texttt{OMP\_NUM\_THREADS=4}, \texttt{OMP\_DYNAMIC=FALSE},
\texttt{OMP\_PROC\_BIND=TRUE}, \texttt{OMP\_PLACES=threads}, and BLAS thread
counts fixed at 4. Recorded package versions: NumPy 2.4.6, faiss-cpu 1.14.2,
pdxearch 0.1 (PDX commit \texttt{fdc62f2d22b3793060abf633cb5407438c7f739b},
clean). Embeddings were produced with PyLate~1.5.0 and
\texttt{lightonai/GTE-ModernColBERT-v1}.

\subsection{IVF configuration}

Both engines index all document token vectors with squared-L2 metric on
L2-normalized inputs. SciFact: 2{,}186 buckets trained on 109{,}300 sampled
points; NFCorpus: 1{,}860 buckets trained on 93{,}000 points; both with
$\texttt{nprobe} = 8$, $L = 100$ hits per query token, seed 0, and the frozen
\texttt{approx\_score} selector. Offline build (train + load) times:
SciFact \SI{18.52}{\second} (FAISS) and \SI{21.46}{\second} (PDX); NFCorpus
\SI{12.27}{\second} (FAISS) and \SI{14.67}{\second} (PDX).

\subsection{BOND kernel configuration}

Dimension checkpoints $\{8, 16, 32, 64, 96, 128\}$; pruning threshold from
the $k$th-largest conservative lower bound over fully scored documents;
500 deterministic prefix seeds (oracle arms receive the exact top-10 free);
strict-inequality pruning with score tie tolerance $10^{-10}$; float64
products and accumulation in both BOND and exhaustive arms. Offline vertical
index construction: \SI{1.755}{\second} (SciFact raw),
\SI{1.681}{\second} (SciFact PCA), \SI{1.224}{\second} (NFCorpus raw);
estimated vertical index footprint on SciFact: \SI{611}{\mega\byte} of values
plus \SI{57}{\mega\byte} of residual norms.

\subsection{Numerical validation}

BOND-versus-exhaustive score agreement on held-out queries: maximum absolute
error $1.78 \times 10^{-14}$ (SciFact raw), $1.07 \times 10^{-14}$
(SciFact PCA), $7.11 \times 10^{-15}$ (NFCorpus raw); ordered top-10 rankings
identical in every arm with no non-tie inversions. The float32 compiled exact
kernel used for IVF reranking matches the NumPy oracle with maximum absolute
score error below $2 \times 10^{-6}$ on the validation workloads, with
identical rankings.
